# danielewworrall.github.io

Daniel Worrall's personal website: hand-written static HTML, published by
GitHub Pages from `main`. This repo is public and every file in it is served
on the site unless `_config.yml` excludes it.

## Read this first: the notes are in a private repo

The setup, conventions, current status and past decisions for this site
live in the private repo **`danielewworrall/website-notes`**, not here.

- Before any work, attach that repo too (in a Claude session, call
  `add_repo` with owner `danielewworrall` and repo `website-notes`, or add
  it in the Claude project's settings) and read its `CLAUDE.md`.
- Record decisions and status there, never in this public repo.
- If you cannot reach it, say so to Daniel rather than working without it.
