# danielewworrall.github.io

Daniel Worrall's personal website: hand-written static HTML, published by
GitHub Pages from `main`. This repo is public and every file in it is served
on the site unless `_config.yml` excludes it.

Before working on the site, read `CLAUDE.md` in the private repo
`danielewworrall/website-notes`. It holds the setup, conventions, current
status and past decisions. Record decisions and status there, not here.
